# 이 폴더의 그림들

| 파일 | 쓰이는 곳 | 만든 것 |
|---|---|---|
| `bard-{idle,talk,dig,play}.webp` | 무대의 라온 | 힉스필드 `seedream_v5_lite` → `tools/make_bard_art.mjs` |
| `hearth-{skewer,pig,cauldron,marshmallow,corn,fish}.webp` | 화로에 걸리는 것들 | `gpt-image-2` → `tools/make_hearth_art.mjs` |
| `hearth-{flame,logs}.webp` | 불꽃과 장작 | 〃 |
| `wall-stone.webp` | 벽과 화로 둘레의 돌결 | 〃 |

화로 쪽 프롬프트는 `.art-work/gen-all.mjs` 에 그대로 들어 있습니다 (저장소 밖, 재생성용).

**CSS 로 남겨 둔 것** — 꼬치걸이대, 불씨, 냄비 거품, 불꽃의 흔들림. 머무는 곳에 따라
쇠 빛과 불빛이 같이 변해야 하는 것들이라, 그림으로 박아 두면 일곱 곳 중 여섯 곳에서 겉돕니다.
벽 돌결도 그림이지만 `soft-light` 로 얹어 결만 빌려 오고 색은 CSS 가 냅니다.

**걸이대에 얹히는 것은 가로로 눕혀 뽑습니다.** 꼬치·통돼지·마시멜로·물고기는
곧은 가로 막대가 관통한 모습이라야 가로대에 걸린 것으로 읽힙니다. 비스듬히 뽑으면
아무도 안 잡고 있는데 대각선으로 떠 있는 모양이 됩니다. 냄비는 서고, 감자와
옥수수는 제 잿더미를 달고 나와 잉걸 위에 놓입니다.

**크기는 그림이 아니라 CSS 가 정합니다.** `tavern.css` 의 `--dish-w` 를 보세요.
상자에 맞춰 늘리면 그림마다 비율이 달라서 마시멜로가 통돼지만 해집니다. 그래서
가로대 너비를 100 으로 두고 서로에 대해 정해 두었습니다 — 통돼지 100, 꼬치 84,
물고기 64, 마시멜로 56, 감자와 옥수수 46, 냄비 44.
그림을 다시 뽑아 가로세로 비가 바뀌면 이 값도 같이 봐 줘야 합니다.

화로 안의 자리도 세 값으로 묶여 있습니다.

| 값 | 뜻 | 지금 |
|---|---|---|
| `--spit-y` | 가로대 높이. 음식 상자의 바닥도 같은 값이라 둘이 어긋날 수 없습니다 | 44% |
| `.logs` 너비 | 장작 더미. 너무 크면 걸이대가 장작 속에 묻힙니다 | 42% |
| `.fire` | 불꽃 세 장을 좌우로 벌려 폭을 냅니다 (`translate` 로 -72% / -28% / -50%) | 높이 54% |

# 바드 그림 갈아 끼우기

지금 무대에 서는 것은 **이 폴더의 그림 넉 장**입니다 (`source: 'image'`).
힉스필드 `seedream_v5_lite` 로 뽑고 `tools/make_bard_art.mjs` 로 다듬었습니다.
만드는 과정은 맨 아래 [어떻게 만들었나](#어떻게-만들었나) 에 적어 두었습니다.

다른 그림이나 영상으로 바꾸려면 여기에 파일을 넣고
`assets/js/character.js` 맨 위의 `ART.source` 만 바꾸면 됩니다.
나머지 코드는 손댈 필요가 없습니다.

```js
export const ART = {
  source: 'image',   // 'svg' | 'image' | 'video'
  ...
};
```

`'svg'` 로 돌리면 예전에 그려 둔 벡터 바드로 돌아갑니다. 그림 파일은 지우지 않아도 됩니다.

---

## 1. 그림 넉 장으로 (`source: 'image'`)

상태마다 한 장씩, 이 폴더에 이 이름으로 넣으세요.

| 파일 | 언제 보이나 |
|---|---|
| `bard-idle.webp` | 가만히 있을 때 (기본) |
| `bard-talk.webp` | 말할 때 — 입을 벌린 모습 |
| `bard-dig.webp`  | 곡을 고르는 중 — 눈 감고 갸웃 |
| `bard-play.webp` | 연주 중 — 류트를 뜯는 모습 |

넉 장을 다 만들 필요는 없습니다. 없는 것은 `bard-idle` 로 대신합니다.
한 장만 넣어도 흔들림·끄덕임 같은 동작은 CSS 가 얹어 줍니다.

### 규격

- **비율 240 × 260** (세로가 조금 김). 어긋나면 여백이 생기지 배지는 않습니다.
- **권장 크기 720 × 780** — 화면에는 232px 로 나오지만 고해상도 기기를 감안한 3배수
- **배경은 반드시 투명** (PNG 또는 WebP). 무대의 불빛 위에 얹히므로 배경이 있으면 사각형이 그대로 보입니다.
- **형식은 WebP 권장.** PNG 도 되지만 서너 배 무겁습니다. 다른 이름을 쓰려면 `ART.images` 경로를 고치세요.
- **한 장 200KB 이하**를 권합니다. 지금 넉 장은 합쳐서 245KB 입니다.

### 구도 맞추기

- 좌우로 꽉 채우지 말고 **양옆 6% 정도 여백**
- 위쪽은 조금만 띄웁니다 — 모자 깃털이 잘리지 않을 만큼
- **아래쪽은 흘려보냅니다.** 류트를 무대 아래로 물리면 무대 바닥의 불빛에 자연스럽게
  잠깁니다. 잘린 선을 바닥 위에 띄워 두는 쪽이 오히려 어색합니다.
- **넉 장의 얼굴이 같은 자리에 같은 크기로** 와야 합니다. 이게 제일 중요합니다 —
  전환은 겹쳐 놓고 투명도만 바꾸는 것이라, 얼굴이 어긋나면 바뀔 때 튑니다.
  `tools/make_bard_art.mjs` 가 턱선을 기준으로 자동으로 맞춰 줍니다.

## 2. 짧은 영상으로 (`source: 'video'`)

```
assets/art/bard.webm       반복 재생할 영상
assets/art/bard-idle.webp  첫 프레임 (영상 받기 전에 보여줄 그림)
```

### 규격

- **소리 없이** 만드세요. 음악 재생기라 영상 소리가 섞이면 안 됩니다. 코드에서 `muted` 로 강제하지만 애초에 무음이 낫습니다.
- **매끄럽게 도는 길이 3~6초.** 첫 프레임과 끝 프레임이 이어져야 끊긴 느낌이 안 납니다.
- **WebM(VP9) 권장**, MP4(H.264)도 됩니다. 확장자만 보고 알아서 처리합니다.
- **2MB 이하**를 권합니다. 휴대폰 데이터로도 열리는 크기여야 합니다.
- 배경 투명이 필요하면 **알파 채널이 있는 WebM**으로 뽑으세요. MP4 는 투명을 못 담습니다.

연주 중이 아닐 때는 영상을 세워 배터리를 아낍니다
(`ART.video.pauseWhenIdle` 을 `false` 로 두면 계속 돕니다).

---

## 알아 둘 점

**색이 따라 변하지 않습니다.** 지금 SVG 는 머리·옷·눈 색이 CSS 변수를 참조해
머무는 곳(참나무 여관 · 얼음 요새 · 마법사의 탑 …)과 곡 분위기를 따라 함께 바뀝니다.
그림이나 영상으로 바꾸면 그 색은 고정됩니다.

무대 뒤 불빛과 음표는 여전히 분위기를 따라가므로 어울리기는 합니다만,
일곱 장소 전부와 맞추고 싶다면 **중간색(갈색·베이지 계열)** 로 그리는 편이 무난합니다.

## 어떻게 만들었나

넉 장이 **같은 사람**이어야 하고, 상태가 바뀔 때 **얼굴이 움직이면 안 됩니다**.
그 두 가지가 까다로운 부분이라 이렇게 했습니다.

**1. 뽑기 — 한 장 먼저, 나머지 셋은 그 한 장을 보고**

`idle` 을 먼저 뽑고, `talk` · `dig` · `play` 는 그 결과를 레퍼런스로 넘겨
"같은 인물·같은 옷·같은 화풍, 표정만 바꿔라" 로 요청했습니다.
넷을 따로 뽑으면 서로 다른 사람이 나옵니다.

- 모델 `seedream_v5_lite`, 1:1, 2048×2048, 넉 장에 4 크레딧
- 배경은 **투명 대신 흰색**으로 뽑았습니다. 무료 플랜에서는 배경 제거가 붙은
  모델(`seedream_v5_pro` 등)을 쓸 수 없어서, 흰 배경으로 받아 아래에서 직접 팠습니다.

상태별로 덧붙인 말:

- idle — `입을 다물고 잔잔히 웃으며 가만히`
- talk — `입을 벌리고 말하는, 눈썹을 살짝 올리고`
- dig  — `두 눈을 감고 고개를 갸웃하며 양피지 악보를 든`
- play — `줄을 뜯는 손을 올리고, 눈을 반짝이며 노래하듯 입을 벌린`

**2. 다듬기 — `tools/make_bard_art.mjs`**

```
cd .art-work && node ../tools/make_bard_art.mjs   # idle-raw.png … play-raw.png → out/*.webp
```

- **배경 파내기** — 가장자리에서 flood fill 로 번져 들어갑니다. 밝기만 보고 자르면
  크림색 외투까지 같이 날아가므로, *밝고 + 무채색*(채널 차이 8 이하)인 것만 배경으로 봅니다.
  판 자리의 RGB 는 흰색이 아니라 먹색으로 칠해 둡니다 — 축소할 때 번지는 테두리가
  흰 테가 아니라 윤곽선의 일부로 보이게.
- **얼굴로 정렬** — 넉 장의 위치를 *얼굴* 기준으로 맞춥니다. 전체 윤곽으로 맞추면
  `dig` 의 악보와 `play` 의 올린 팔 때문에 기준이 흔들립니다. 살색 화소의 덩어리에서
  가로는 중심, 세로는 **턱선**을 씁니다 (넉 장에서 0.5px 안쪽으로 일치했습니다).
- **한 배율로** — 넉 장에 같은 배율을 먹여 상태가 바뀔 때 크기가 변하지 않게 합니다.
  류트는 아래로 흘려보냅니다. 잘린 선이 무대 바닥에 떠 있는 것보다 자연스럽습니다.
- 720×780 WebP, 한 장 56~64KB.

**3. 확인**

넉 장을 겹쳐 놓고 반투명으로 포개 보면 얼굴·모자·깃털이 그대로 겹칩니다.
어긋나면 전환할 때 얼굴이 튑니다.
